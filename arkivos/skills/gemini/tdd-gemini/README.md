# tdd (variante Antigravity / Gemini)

Skill de Test-Driven Development (Red-Green-Refactor) adaptada para o Google Antigravity, em Português do Brasil, alinhada com testes de integração em banco local e progressive disclosure (`references/boas-praticas-testes.md` carregado apenas quando houver mocks ou casos complexos). Este arquivo é só para humanos; o agente lê apenas o `SKILL.md`.

## Instalação no Antigravity

- **Disponível em qualquer projeto sob demanda (sem carregar no prompt até pedir):** copie o conteúdo para `~/.gemini/config/skills/tdd/`.
- **Apenas em um projeto específico:** copie o conteúdo para `.agents/skills/tdd/`.

Uso no chat: peça `tdd` (ex.: *"implementa isso usando a skill tdd"*).
