# auditor (variante Antigravity / Gemini)

Skill de Code Review técnico somente leitura (bugs de lógica, N+1, vazamento de recursos, erros engolidos, contratos e avaliação crítica de contrapropostas) otimizada para o Google Antigravity. Este arquivo é só para humanos; o agente lê apenas o `SKILL.md`.

## Instalação no Antigravity

- **Disponível em qualquer projeto sob demanda:** copie o conteúdo para `~/.gemini/config/skills/auditor/`.
- **Apenas em um projeto específico:** copie o conteúdo para `.agents/skills/auditor/`.

Uso no chat: peça `auditor` ou `code review` (ex.: *"roda o auditor nessa branch"*).
