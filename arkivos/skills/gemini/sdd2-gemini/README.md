# sdd-2 (variante Antigravity / Gemini)

Skill de Spec-Driven Development 2.0 (Elephant Goldfish Model) otimizada para o Google Antigravity (`invoke_subagent` com `TypeName: "research"`, `Model: "flash"` / `"flash_lite"` e ativação sob demanda). Este arquivo é só para humanos; o agente lê apenas o `SKILL.md`.

## Instalação no Antigravity

- **Disponível em qualquer projeto sob demanda (sem carregar no prompt até pedir):** copie o conteúdo para `~/.gemini/config/skills/sdd2/`.
- **Apenas em um projeto específico:** copie o conteúdo para `.agents/skills/sdd2/`.

Uso no chat: peça `sdd-2` (ou `sdd-2 <fase>`).
Fases: `bootstrap`, `brainstorm`, `draft`, `review`, `drift`.
