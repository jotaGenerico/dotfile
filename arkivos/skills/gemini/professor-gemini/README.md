# professor (variante Antigravity / Gemini)

Skill de ensino guiado sob demanda que suspende temporariamente a concisão extrema do `GEMINI.md` para explicar conceitos, fluxos e erros passo a passo sem editar arquivos do projeto. Este arquivo é só para humanos; o agente lê apenas o `SKILL.md`.

## Instalação no Antigravity

- **Disponível em qualquer projeto sob demanda:** copie o conteúdo para `~/.gemini/config/skills/professor/`.
- **Apenas em um projeto específico:** copie o conteúdo para `.agents/skills/professor/`.

Uso no chat: peça `modo professor` ou `usa a skill professor`.
