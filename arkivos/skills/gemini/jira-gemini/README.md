# jira (variante Antigravity / Gemini)

Skill sob demanda para verificar, criar subtarefas/tickets na sprint vigente e dar baixa ("Concluído") no Jira sem perder o vínculo com a branch/PR atual. Este arquivo é só para humanos; o agente lê apenas o `SKILL.md`.

## Instalação no Antigravity

- **Disponível em qualquer projeto sob demanda:** copie o conteúdo para `~/.gemini/config/skills/jira/`.
- **Apenas em um projeto específico:** copie o conteúdo para `.agents/skills/jira/`.

Uso no chat: peça explicitamente (ex.: *"vai lá no Jira, vê se tem essa tarefa/subtarefa e cria"* ou *"vai lá no Jira e dá baixa"*).
